# 筋トレ記録アプリ

種目・重量・回数・セット数を記録し、進捗をグラフで確認できるシンプルな筋トレ記録アプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）で、記録はブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで開くだけで利用できます。ローカルで確認する場合は、例えば以下のように簡易サーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pages で公開する場合は、リポジトリの Pages 設定でこのブランチ（または `main`）のルートを公開すれば、そのまま利用できます。

## 機能

- 日付・種目・重量・回数・セット数・メモを記録
- 種目名はこれまでの入力から入力補完
- 記録一覧（日付ごとにグループ化、削除可能、種目で絞り込み可能）
- 概要（総記録数・種目数・直近7日間の実施日数）
- 種目ごとの重量推移グラフ（ホバーで日付と重量を表示）
- ライト/ダークモード対応

## データについて

記録はすべてブラウザ内の `localStorage` に保存され、サーバーには送信されません。別の端末やブラウザとはデータが共有されない点にご注意ください。
